## 优化

- 降低菜单栏常驻空转开销：10 秒额度快轮直接复用未变更的用量简析、工具明细与缓存命中模型；菜单栏两行文字与外观未变化时不重复重绘图标；诊断状态文件仅在内容变化或心跳到期时完整序列化写盘。
- 优化本地 Token 扫描与长期缓存体积：多来源聚合改为单趟原地合并，静止会话文件超过保留窗口的旧日数据会随日期滑动自动清理（含 Hermes 卸载后的缓存明细），避免长期使用后缓存文件持续膨胀。
- 优化应用内更新体验：联网下载前先完成版本校验、多副本冲突与 LaunchAgent 路径检查，异常时立即中止提示，不再白等下载；换包前停止旧进程改为短间隔轮询等待，退出快时更快推进、繁忙时更不易误判超时。
- 开机自启的 `launchctl` 加载与卸载移至后台串行执行，避免切换开关或登录高负载时卡顿主线程。

## 修复

- 修复本地扫描、网络回调与界面刷新并发访问日期解析器/格式化器可能引发的竞态，同时修复切换系统时区或非公历日历下的归日偏差，以及午夜 00:00 附近同帧各卡片日期错位。
- 修复月度主接口失败、由 Kimi Code 备援额度兜底时未更新月度成功时间，导致 10 分钟后误显示「已过期」警告的问题。
- 修复全新 macOS 用户目录缺少 `~/Library/LaunchAgents` 时首次开启开机自启失败的问题，写入前自动创建目录。
