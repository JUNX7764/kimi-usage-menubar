## 新增
- 新增「额度周期回顾」：按真实观测的 7 天额度窗口展示每轮已用百分比，支持回看正常到期、窗口变化与观测缺口。
- 支持悬停查看详情、点击固定选择、左右键跨周期浏览、翻页及逐批加载更早记录。
- 历史按 Kimi Code 凭据作用域隔离并仅保存在本机；不保存原始 API Key，也不从本地 Token 反推额度。

## 优化
- 使用细宽微圆角双柱、空心当前轮和浅蓝选中底色；每轮日期下直接显示已用百分比。
- 当前轮始终靠右，单页隐藏无效翻页控件；卡片支持独立折叠、深浅色和三种面板背景。

## 使用提示
- 历史从首次成功读取 7 天额度后开始，不回填安装前记录；观测缺口不会按零用量处理。
- API Key 轮换后会使用新的历史分区，旧凭据的记录不会串联到新分区。
