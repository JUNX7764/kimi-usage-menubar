## 新增

- 头部「···」统一面板设置：五张内容卡（用量进度 / 用量情况 / 用量简析 / 额度周期回顾 / 工具明细）可独立显隐与上下排序，改动即时生效并记住；全部隐藏时给出说明与一键恢复。隐藏 ≠ 收起——隐藏的卡片仍正常获取数据与统计。
- 卡片设置页含恢复默认 / 返回 / 完成（完成绑回车键）；打开时接管键盘焦点，后台刷新重建后焦点不丢。

## 优化

- 额度周期回顾对齐 GLM 用量 v1.5.3：每轮一根居中 12pt 上限槽 + 底部已用填充（0% 不画、100% 填满），「已用 / 距上限」图例、图区 100% 刻度、图下选中轮次状态行；当前轮轻量填充与柔和列底分级；图标更新为时钟循环，与用量简析区分。
- 修复额度槽填充顶边中部的异常凸起（圆弧方向错误导致的角部凹陷）。
- 用量简析：日环比 / 7 日环比改为涨跌胶囊（窄面板自动两行、数字不截断）；每日柱顶 1.5pt 微圆角；选中日期数值 320ms 平滑过渡（尊重系统「减少动态效果」）。
- 个别会话文件读取失败不再让「用量情况」显示常驻错误，扫描成功时间正常推进；诊断计数见 status.json。
- 周期回顾详情改由画布原生 tooltip 呈现，点击固定后仍可用左右方向键逐轮查看。

## 使用提示

- 卡片布局保存在本机；「恢复默认」只重置卡片布局，不动背景样式与折叠状态。
- 周期历史口径不变：仍按 Kimi Code 凭据作用域本机保存，不保存原始 API Key，不从本地 Token 反推额度。
